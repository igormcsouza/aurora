# Project layout

Aurora keeps a channel project in a fixed shape.

```text
<project>/
  preferences.json            persona, voice, palette, tone, defaults
  draft_videos/<slug>/        videos in production: everything, incl. drafts, voice tests, logs, caches
  published_videos/<date>_<slug>/
                              package/ (video.mp4, thumbnails, subtitles.srt, package.md), shorts/,
                              cost.json, published.json, and what rebuilds the video
                              (plan.json, narration.md, sources.md, scenes/ ...)
  aurora/                     feedback.jsonl, insights.md, topics.log, jokes.jsonl, ideas.jsonl,
                              batch.md, research.md, tiers.jsonl, analytics/
  channel/                    avatar, banner, watermark, mascot PNGs
  video-kit/                  tooling generated by preflight (venv and node_modules git-ignored)
  .aurora_trash/              reversible trash, emptied only on your OK
```

`organize.py` does all moving and deleting. Never move video files by hand. Commit `aurora/feedback.jsonl` and `aurora/insights.md` if your team shares them.

## Adopting an existing project

```text
/aurora adopt
```

Runs `organize.py scan` (a dry run): every video folder found, loose files, what looks finished, and the proposed layout. Nothing moves until you approve, and trash is reversible.

## Inside a video folder

`state.json`, `plan.json`, `narration.md`, `visual_assets.md`, `assets/`, `scenes/` (`spec.json`, `cues.json`, `durations.json`, `NN.mp3`, `final/NN.mp4`), `package/`, logs. `package/` holds only what you publish.
